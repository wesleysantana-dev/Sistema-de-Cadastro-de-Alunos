# Sistema de Cadastro de Alunos ---

Projeto prático de cadastro de alunos com Python e SQLite.

# O que o programa faz
- Cria o banco de dados `escola.db` com a tabela `alunos`
- Pede o nome e a nota de um aluno pelo teclado
- Salva os dados no banco

## Como rodar
1. Ter o Python 3 instalado
2. No terminal, rodar: `python CADASTRO-ALUNO.PY`

## O que estou aprendendo com este projeto
- Conectar Python a um banco de dados com `sqlite3`
- Criar tabelas e inserir dados com SQL (`CREATE TABLE`, `INSERT`)
- Receber dados do usuário com `input()`
